所有 6 个核心页面设计已通过迭代审核并批准:

1. **首页 Landing** — 导航栏(无"浏览任务"), Hero(深色渐变遮罩+轮播点), 三列特性卡片, Footer
2. **Dashboard** — 统计卡片(进行中可点击), 展开工人卡片(完成任务绿色/结束任务红色), 双层确认弹窗(全屏遮罩)
3. **任务浏览页**(自由职业者) — 搜索+筛选栏, 双列卡片, 详情页 2fr/1fr 布局
4. **发布任务**(雇主) — 双列表单: 左(名称/详情/要求), 右(预算/分类/技能/时长/地点/截止日期)
5. **管理申请**(雇主) — 申请者卡片(通过绿色/拒绝描边), 状态筛选
6. **消息系统** — D款铃铛导航图标, 280px 对话列表 + 全高聊天窗口
7. **头像下拉菜单** — 点击头像弹出: 切换为[另一端] / 分隔线 / 退出账号(红色), 无 emoji
