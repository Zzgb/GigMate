# GigMate 前端页面设计规范

> 日期: 2026-05-22
> 项目: GigMate 兼职平台

---

## 1. 设计语言

### 1.1 风格
Tahoe 风格 · macOS 风格设计语言。

- 背景色: `#f5f5f7`
- 主文字: `#1d1d1f`
- 次要文字: `#86868b`
- 品牌蓝: `#007aff`
- 成功/完成: `#30d158`
- 错误/取消: `#ff3b30`
- 警告/待审核: `#f59e0b`
- 白色卡片: `#ffffff`
- 卡片分割线: `rgba(0,0,0,0.05)`

### 1.2 圆角系统
- 大圆角卡片: `20px`
- 小元素/标签: `8px` / `12px`
- 胶囊/按钮: `999px` / `14px`
- 头像: `50%` (圆形) 或 `14px` / `10px` / `8px` (方形圆角)
- 消息气泡: `14px 14px 14px 4px` (对方), `14px 14px 4px 14px` (自己)

### 1.3 阴影
- 卡片阴影: `0 4px 24px rgba(0,0,0,0.04)` / `0 2px 20px rgba(0,0,0,0.04)`
- 毛玻璃导航: `backdrop-filter: blur(20px)`, `background: rgba(255,255,255,0.8)`

### 1.4 货币
- 使用人民币 `¥` 符号
- 显示格式: `¥200-500`、`¥150/天`

## 2. 路由结构

```
/                   首页 Landing（未登录可见）
/(auth)/

/(dashboard)/
```

## 3. 页面设计

### 3.1 首页 Landing (`/`)

**导航栏**
- 左: GigMate logo (渐变黑)
- 右: 登录（文字）、注册（黑底白字胶囊按钮）
- 无「浏览任务」入口

**Hero 区域**
- 深色遮罩渐变背景: `linear-gradient(135deg, rgba(0,0,0,0.45), rgba(0,0,0,0.55))`
- 标题: 「兼职就该这么简单」白色 `2.8rem`
- 副标题: 白色 75% 透明度
- 双 CTA 按钮: 「我要雇佣」白底黑字、「找工作」半透明描边
- 底部 3 个轮播小圆点指示器（预留横向轮换背景图）

**特性三卡片**
- 网格 `1fr 1fr 1fr`
- 每张: icon → 标题 → 描述
- 发布招聘、浏览任务、互相评价

**Footer**
- © 2026 GigMate · 关于 · 联系

### 3.2 Dashboard / 控制台 (`/dashboard`)

**导航栏**（登录后）
- 左: GigMate logo + 首页/任务/控制台
- 右: D款铃铛图标 + 角色名(雇主/自由职业者) + 头像（可点击）
- 点击头像弹出下拉菜单:
  - 切换为[另一端]（如当前雇主 → 显示「切换为自由职业者」）
  - 分隔线
  - 退出账号（红色）

**概览页**
- Welcome 问候语
- Tabs: 概览 / 我的任务 / 发布任务
- 三个统计卡片: 进行中(可点击) / 已完成 / 总申请
- 最近任务列表（显示名称 + 状态在右侧，不显示金额）

**「进行中」展开视图**
- ← 返回概览
- 自由职业者卡片列表（每位工人一张卡）:
  - 头像 (44px, 圆角14px)
  - 姓名 + 任务名称
  - 状态标签
  - 消息按钮（带红点未读提示）
  - 操作按钮: 完成任务（绿 `#30d158`）、结束任务（红 `#ff3b30`）

**完成任务（1步确认弹窗）**
- 全屏暗化遮罩 `rgba(0,0,0,0.35)` + `backdrop-filter: blur(2px)`
- 居中白色卡片 360px, `border-radius: 20px`
- 标题「确认操作?」
- 描述「确定完成该任务并付款?」
- 按钮: 取消（红） / 确定（黑）

**结束任务（2步确认弹窗）**
- Step 1: 标题「确认操作?」描述「确定要结束该任务?」取消（红）/ 确定（黑）
- Step 2: 标题「是否重新发布此任务?」取消（红）/ 重新发布（蓝 `#007aff`）
  - 点击「重新发布」→ 跳转发布任务页并预填当前任务信息

### 3.3 任务浏览页（自由职业者）(`/tasks`)

**筛选栏**
- 搜索框（左侧输入，右侧黑色「搜索」按钮）
- 视图切换: 双列/单列
- 筛选胶囊: 全部 / 任务类型 / 专业领域 / 工作地点 / 预算范围 / 排序

**任务卡片**（双列网格）
- 标题 + 分类·地点·时间 + 状态标签（招募中 绿色）
- 描述摘要
- 技能标签（灰底小圆角）
- 价格（`¥` 格式）+ 「立即申请」按钮
- 卡片可点击进入详情

**任务详情页**
- ← 返回任务列表
- 左(2fr): 任务详情、任职要求、技能标签、发布者评价
- 右(1fr)边栏: 预算(大字)、预计时长·工作方式·申请人数·截止日期、雇主信息、「立即申请」按钮

### 3.4 发布任务（雇主）(`/tasks/new`)

**双列表单**
- 左(3fr):
  - 任务名称 (input)
  - 任务详情 (textarea，min-height 100px)
  - 任职要求 (textarea，min-height 80px)
- 右(2fr):
  - 预算 ¥ (最低 — 最高)
  - 分类 (dropdown)
  - 技能标签 (标签 ✕ + 添加按钮)
  - 预计时长 / 工作方式
  - 工作地点（线下）
  - 截止日期
  - 「发布任务」按钮

### 3.5 管理申请（雇主）(`/tasks/[id]/applications`)

**页面结构**
- ← 返回我的任务
- 标题: 「任务名 · 申请列表」+ 共 N 人申请 + 状态
- 筛选: 全部 / 待审核 / 已通过

**申请者卡片**
- 头像(44px) + 姓名 + 经验年数 + 状态标签(待审核黄色/已通过绿色)
- 申请留言
- 技能标签
- 统计数据: ⭐评分 / 已完成单数 / 回复率
- 操作按钮: 通过（绿）/ 拒绝（描边灰）
- 已通过状态: 「已通过 · 等待对方确认」

### 3.6 消息系统 (`/messages`)

**全局导航铃铛**
- D款极简线条铃铛: 16x20px, `fill="none"`, `stroke="#1d1d1f"`, `stroke-width="1.5"`
- 未读红点: `7x7px`, `#ff3b30`, 右上角偏移

**对话记录列表**（左侧 280px）
- 标题「对话记录」
- 列表项: 头像(28px 圆角8px) + 名称 + 时间 + 任务名(蓝色/灰色小字) + 消息预览 + 未读数红点
- 选中项背景 `#f5f5f7`

**聊天窗口**（右侧自适应）
- 头部: 头像(32px 圆角10px) + 名称 + 「关于 · 任务名 →」蓝色链接
- 消息区域: 对方气泡灰底 `#f5f5f7` 左下圆角4px / 自己气泡黑底 `#1d1d1f` 右下圆角4px
- 底部: 输入框 `#f5f5f7` + 黑色「发送」按钮

## 5. 设计笔记

- 所有导航栏统一：路径 `/`、`/tasks`、`/dashboard` 使用相同布局结构
- 登录前导航: GigMate + 登录/注册
- 登录后导航: GigMate + 首页/任务/控制台 + 铃铛D + 角色名 + 头像
- 首页为纯 Landing 页，未登录用户可见
- 未读消息通过铃铛右侧红点全局提示
- 任务状态: 招募中(绿色) / 进行中 / 已完成
- 任务状态流转: OPEN → IN_PROGRESS → COMPLETED
